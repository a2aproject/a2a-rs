# A2A Rust SDK

!!! note "Under construction"

    These pages are being written. The plan and its tasks are in
    [#521](https://github.com/a2aproject/a2a-rs/issues/521).

`a2a-rs` is the Rust SDK for the
[Agent2Agent (A2A) protocol](https://a2a-protocol.org/latest/). The hello world
agent in the `examples` crate mounts its bindings like this:

```rust
--8<-- "examples/src/helloworld/server.rs:routers"
```
